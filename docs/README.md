## How to Read These Documents

Each document follows this structure:

1. **Purpose** — what the module does in 1–2 sentences
2. **Who can access it** — required role / permissions
3. **Key features** — bullet list of capabilities
4. **Actions** — every button, link, and form with what it does
5. **Modals & Dialogs** — detailed description of every popup
6. **Related modules** — cross-references
7. **Common workflows** — step-by-step for typical tasks
8. **Known limitations / tips** — gotchas to watch out for

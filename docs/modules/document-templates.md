# Document Templates Module

## Purpose
Customize the layout and styling of PDF documents (offers, invoices, proformas) generated by the system.

## Key Features
- Multiple templates per document type (offer / invoice / proforma / contract / generic)
- One default template per type (used when no specific template is selected)
- Customize: page size (A4/Letter), margins, colors, fonts
- Header: company logo, name, address, contact
- Footer: page numbers, verification hash, legal text
- Item table styling: columns, stripes, borders
- Tax/total section layout
- Notes/terms section
- QR code for document verification (auto-generated)

## Actions

| Action | What it does |
|--------|-------------|
| New Template | Opens editor |
| Edit | Opens editor with existing template |
| Duplicate | Creates a copy |
| Set as default | Marks this template as the default for its type |
| Preview | Generates a sample PDF with the template |
| Delete | Removes template (defaults cannot be deleted) |

## Template Editor

### Layout
- Page size: A4 / Letter
- Page margins: top / bottom / left / right (mm)
- Header height, footer height

### Branding
- Primary color (hex) — used for headings, borders, accents
- Logo URL — auto-filled from tenant branding
- Company name, address, contact info — auto-filled from tenant

### Typography
- Heading font family, size
- Body font family, size
- Line height

### Item Table
- Show/hide columns: #, Product, Description, Qty, Unit, Price, Discount, Tax, Total
- Stripe color (alternating rows)
- Border color
- Header background color

### Sections
- Header text (free HTML)
- Footer text (free HTML)
- Terms & conditions (free HTML)
- Notes section

### Verification
- QR code position: top-right / bottom-right / footer
- Verification hash format
- "Scan to verify" text

## Tips
- Keep one default per type — the system uses it when no specific template is selected
- Use the Preview button to see how the PDF looks before saving
- QR codes are auto-generated and link to /verify/[code] for document authentication
- Margins are in millimeters — typical A4 margins are 15-20mm
- Primary color should match your brand — use a hex code like #0f766e

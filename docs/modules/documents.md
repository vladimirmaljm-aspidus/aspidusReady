# Documents Library Module

## Purpose
Shared document library — upload contracts, specs, certificates, any file. Share with partners via the portal.

## Key Features
- Upload files (any type)
- Categorize: contract / invoice / spec / other
- Set visibility: visible to partner (portal) or internal only
- Link to partner
- Download / preview

## Tips
- Files are stored in Supabase Storage (private buckets)
- "Visible to partner" = true makes the document appear in the partner's portal
- Use categories to organize — the portal filters by category

# Custom Dashboard Module

## Purpose
Build your own dashboard with custom KPIs, charts, and tables. Save multiple dashboards per user.

## Key Features
- Add widgets: KPI card, chart (bar/line/pie), table, text block
- Arrange via drag-and-drop
- Configure data source per widget (entity + aggregation)
- Save multiple dashboards
- Share with team (future)

## Tips
- Build a "Sales" dashboard with deals by stage + offers this month + top partners
- Build a "Finance" dashboard with invoices outstanding + revenue + ERP summary
- Custom dashboards are per-user

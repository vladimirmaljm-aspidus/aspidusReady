# Super Admin Overview Module

## Purpose
Platform-level dashboard for super_admins — see all tenants, total users, activity across the entire platform.

## Key Features
- Total tenants, users, partners, deals, offers, invoices across ALL tenants
- Per-tenant breakdown (users, partners, deals, offers, invoices)
- Active tenants count
- Recent activity (across all tenants)
- Recent user logins

## Tips
- Only super_admin can access this module
- Use this to monitor platform health + identify inactive tenants
- Click a tenant to drill into its data (switches your active tenant)

# API Integrations Module

## Purpose
View data from external logistics, customs, and market news APIs. Configure API keys for external services.

## Tabs

### Customs Tab
- Customs regulations by country
- Import/export restrictions
- HS code lookup
- Duty rates

### Logistics Tab
- Shipment tracking (from external logistics APIs)
- Container status
- ETA updates

### Market News Tab
- Commodity market news
- Trade regulations
- Filter by impact (positive/negative/neutral) and region

## Tips
- This module pulls from external APIs — configure keys in Settings
- Market news is updated hourly
- Use customs data to check requirements before shipping to a new country

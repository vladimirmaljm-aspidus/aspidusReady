# Logistics & Customs Module

## Purpose
Track shipments and customs regulations. Integrates with external logistics APIs.

## Logistics Tab
- List of shipments (filter by status: pending / in_transit / delivered / delayed)
- Fields: shipment number, origin, destination, carrier, mode (sea/air/road/rail), ETA, status
- Container tracking
- Customs status per shipment

## Customs Tab
- Customs regulations by country
- HS code lookup
- Import/export restrictions
- Duty rates

## Tips
- Logistics data can be synced from external APIs (Settings → API Integrations)
- Use the customs tab to check requirements before shipping to a new country

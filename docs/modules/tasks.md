# Tasks Module

## Purpose
Personal task list for internal staff. Not visible to portal clients.

## Key Features
- Create tasks with title, description, priority (low/medium/high), due date
- Mark as done / undo
- Filter by status (active/done), priority
- Tasks are per-user (each staff member sees their own)

## Tips
- Tasks are personal — use them for your to-do list
- Due dates show in red when overdue
- No assignment to other users (use a different system for team task management)

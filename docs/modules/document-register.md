# Document Register Module

## Purpose
Versioned document register — track every version of every official document (offers, invoices, proformas). V1/V2/V3 numbering.

## Key Features
- List all registered documents (filter by type, status, partner)
- Version history per document (V1, V2, V3...)
- Status: current / superseded / archived
- When you send a new version of an offer, the old one is superseded
- File URL stored for each version

## Tips
- The register is auto-populated when you send offers/invoices/proformas
- Use this to prove what version was sent when (audit trail)
- "Current" status = the active version; "Superseded" = older version
